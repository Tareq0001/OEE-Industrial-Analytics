# OEE Industrial Analytics V2 ❖
### النمط العسيري التقني المبتكر (Modern Neo-Asiri Tech Fusion)

منظومة هندسية وصناعية متقدمة لحساب الكفاءة الكلية للمعدات (OEE)، رصد الخسائر الست الكبرى، ومخططات باريتو 80/20، مصممة بنمط بصري فريد يدمج بين **عراقة فن القط العسيري الهندسي** والتصميم الرقمي التنفيذي الحديث.

## 🎨 الهوية البصرية (النمط العسيري التقني):
- **زخارف القط العسيري:** شرائط هندسية علوية ومحاريب زوايا بألوان تراث منطقة عسير الأصيلة:
  - الأحمر القاني العسيري (`#dc2626`)
  - الذهبي التراثي الدافئ (`#f59e0b`)
  - الأخضر الفيروزي وعرعر السودة (`#10b981`)
  - الأزرق النيلي (`#3b82f6`)
- **الخلفية الصخرية العميقة:** مستوحاة من صخور جبال السروات وعسير الداكنة (`#070b14`).

---

## 🌟 المزايا الهندسية:
- **عداد OEE الدائري ثلاثي المحاور:** يعرض الإتاحة (A)، الأداء (P)، والجودة (Q).
- **مخطط الشلال التنازلي (Waterfall Cascade):** تفكيك هدر ساعات الوردية دقيقة بدقيقة.
- **مخطط باريتو 80/20 المزدوج:** تحديد الأسباب الحرجة المسؤولة عن 80% من الأعطال.
- **سيناريوهات صناعية فورية:** سيارات، صيدلة، إلكترونيات، وتعدين.
- **ثنائي اللغة بالكامل (العربية / English).**
